## Working guidelines

- **Always use Context7** when you need library/API documentation, code generation, or setup/configuration steps.
- **Always use the frontend-design plugin** for any matter of design, or when creating a frontend for a page.
- **Persist what you discover.** When you have to search the project for something (a feature, symbol, config, or convention) because Serena's memories didn't cover it, save what you found to Serena memory once you find it — update the relevant existing memory or create a new one — so future sessions don't rediscover it. Only save durable, non-obvious facts, not one-off task details. This repo has an active Serena project (`dad'sproject`); start from `mem:core` for the memory graph.
